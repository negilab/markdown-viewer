# Markdown Viewer

Markdownを読みやすく表示して、そのまま書き直せる画面です。`**` や `#` などの記号を見ずに書けます。PCでもiPhoneでも使えます。

公開版: https://negilab.github.io/markdown-viewer/

## 使い方

- 右上の「開く」から、この端末かGoogleドライブのファイルを選びます。PCでは、ファイルを画面に置いても開けます
- 行のはじめで「/」を押すと、見出し・リスト・表などのメニューが出ます
- 文字を選ぶと、太字やリンクのボタンが出ます（iPhoneは上に書式のバーが常に出ます）
- 行の左の ⋮⋮ で段落ごと並べ替えます。複数の段落にまたがって文字を選んでから ⋮⋮ をつかむと、選んだ段落をまとめて動かせます
- `Ctrl`（Mac は `⌘`）+ `Shift` + `↑` / `↓` で、選んだ段落を上下に1つずつ動かします。PCは編集パネル、iPhoneは書式のバーにも「上へ移動」「下へ移動」のボタンがあります。箇条書きの中なら項目ごと、表の中なら表ごと動きます
- `- ` `## ` `- [ ] ` と打つと、その場で箇条書き・見出し・チェックに変わります
- 箇条書き・番号付き・チェックは `Tab` / `Shift` + `Tab` で何段でも字下げできます（1回で下げられるのは上の項目より1段深くまで）。PCは編集パネル、iPhoneは書式のバーにも字下げのボタンがあります
- 右上の「閲覧に切り替え」で、書き換えずに読むだけの表示にできます

PCでは左に「編集パネル」が出ます。元に戻す・やり直す、見出し、太字などの文字の書式、箇条書き・チェック・引用、表・区切り線などの挿入と、目次・文字数がまとまっています。カーソル位置で効いている書式はボタンが光ります。左上のボタンで開け閉めでき、その状態は端末ごとに覚えます。

右上の設定ボタンで、文字の大きさ（4段階）、本文の幅（PCのみ、4段階）、テーマ（自動・ライト・ダーク）を選べます。設定は端末ごとに覚えます。メニューの下の「最終更新」の日付で、画面が最新かどうかを確かめられます。

### 保存

「保存」（`Ctrl` + `S`）の行き先は、ファイルを開いた場所と使っているブラウザによって変わります。

| 開いた場所・環境 | 保存のしかた |
|---|---|
| Googleドライブ | ドライブのファイルに上書き。開いたあとにドライブ側で更新されていたら、上書きする前に確かめる |
| PC の Chrome / Edge | 開いたファイルにそのまま上書き。元のファイルが分からないときは保存先を選ぶ |
| iPhone / iPad | 共有メニューが開く。「"ファイル"に保存」で保存先を選ぶ |
| それ以外 | ダウンロード |

保存していない編集は、この端末のブラウザに下書きとして残り、次に開いたとき復元されます。

保存するとき、Markdownの書き方が少し整えられます（箇条書きは `- `、表の列幅がそろう、など）。先頭の `---` の情報欄（フロントマター）と改行コードはそのまま残します。

### 変わった所に色を付ける

前に開いたときから変わった所は、文字の色が変わります。Claude Code が直した所を、開いたときに確かめられます。

- 比べる相手は、この端末で前に開いた・保存したときの中身です。ファイルごとに新しい40件まで覚えます
- この端末で初めて開くドライブのファイルは、Googleドライブに残っている1つ前の版と比べます
- 消された文は、手前の段落の終わりに「削除あり」の印が出ます。PCでは印に重ねると、消えた文が出ます
- 画面の下の帯に変わった所の数が出ます。「次の変更へ」で順に移り、「色を消す」で色を消します
- 色は表示だけです。保存しても、ファイルには何も入りません

### PC のパスから開く（Claude Code のリンク）

`#path=<PCのパス>` を付けて開くと、Googleドライブの中から同じファイルを探して開きます。保存するとドライブ経由でPCの現物に戻ります。

```
https://negilab.github.io/markdown-viewer/#path=C:%5CUsers%5C81809%5Cclaude%5Cメモ.md
```

- `G:\マイドライブ\...` のファイルはそのまま開けます
- `C:\...` のファイルは、Googleドライブのパソコン用アプリで、そのフォルダを「Google ドライブと同期」にしておく必要があります
- ファイル名で探し、親フォルダの名前がパスと何段一致するかで選びます。同じくらい一致するものが複数あれば選んでもらいます
- 初回はGoogleへのログインのボタンを押します。ログインは約1時間この端末に残り、その間はリンクを押すだけで開きます
- 以前の `beta.html#path=...` のリンクも、そのまま開けます

PC の Claude Code には、`CLAUDE.md`（全体用は `C:\Users\<名前>\.claude\CLAUDE.md`）に次のように書いておくと、リンクを付けてくれます。

```
mdファイルのパスを伝えるときは、次の形のリンクも添える（パスは URL エンコードする）:
[📱 携帯で開く](https://negilab.github.io/markdown-viewer/#path=<パス>)
```

### URLで本文を渡す（iPhoneのショートカットなど）

URLの `#` のあとに本文を付けて開くと、そのまま表示します。

```
https://negilab.github.io/markdown-viewer/#name=メモ.md&md=<URLエンコードした本文>
```

- `md` は必須、`name` は省略できます（省略すると「共有.md」）
- `#` 以降はサーバーに送られません。読み込んだあとはURLから取り除きます

iPhoneでは、ショートカットAppで次のように組むと、ファイルAppの共有メニューから開けます。

1. ショートカットの詳細で「共有シートに表示」をオンにし、受け取る種類を「ファイル」にする
2. 「テキストを取得」で、ショートカットの入力から本文を取り出す
3. 「URLエンコード」で本文をエンコードする
4. 「テキスト」に `https://negilab.github.io/markdown-viewer/#md=` と書き、後ろにエンコードした本文をつなげる
5. 「URLを開く」でSafariに渡す

## Googleドライブとの連携

ドライブのファイルを開いて、そのまま上書き保存できます。PCのパスからファイルを探すため、権限はドライブ全体（`drive`）を使います。

「開く」→「Googleドライブから開く」で、ドライブの md ファイルが最近更新した順に並びます。ファイル名や本文で探すこともできます。

使うには `src/drive.js` の `GOOGLE` に、Google Cloud で作った OAuth クライアントID を入れてビルドします。空のままなら、ドライブのメニューは出ません。API キーは使いません。

## 安全性

読み込んだファイルは、この端末と、ドライブから開いたときのGoogleドライブの間でだけやりとりします。ほかの場所へは送りません。文字は Inter と Noto Sans JP（Google Fonts）を読み込みます。

## 作り直す

画面は `index.html` 1つにまとまっています。元のコードは `src/` にあり、次のコマンドで `index.html` を作り直します。

```
npm install
npm run build
```

編集部品は [Milkdown](https://milkdown.dev/)（MIT）です。

## 動作環境

Chrome / Edge / Firefox / Safari の最近のバージョン。

対応する拡張子は `.md` `.markdown` `.mkd` `.mdown` `.mdx` `.txt` です。文字コードはUTF-8。
