# Markdown Viewer

Markdownファイルをドラッグ&ドロップすると、インデントと表を読みやすい形で表示するビューアです。

HTMLファイル1つだけで動きます。インストールは要りません。ダブルクリックでブラウザが開き、そこにファイルを落とすだけです。公開版は https://negilab.github.io/markdown-viewer/ で使えます。

## 使い方

1. `index.html` をダブルクリックします
2. 開いた画面に `.md` ファイルをドラッグ&ドロップします

`Ctrl` + `V` でクリップボードのMarkdownも読み込めます。複数のファイルを一度に落とすと、左のリストで切り替えられます。

### 編集と保存

表示したまま、直したい段落だけをその場で書き換えます。切り替えのタブはありません。

| | PC | スマホ |
|---|---|---|
| 編集を始める | 段落をダブルクリック | 段落を長押し、または右下の「✎ 編集」を押してから段落をタップ |
| 確定する | `Esc`、または本文の外側をクリック | キーボードの上の「完了」 |
| 書式のボタン | サイドバーの下の「編集キット」 | キーボードのすぐ上(「⋯」で残りのボタン) |
| 目次・ファイル | 左のサイドバー | 左上のボタンで下から出るシート |

- 編集中も、目次や文字数は打つたびに更新されます
- 「戻る / やり直す」は `Ctrl` + `Z` / `Ctrl` + `Shift` + `Z` とキットのボタン。段落を移っても戻れます
- 「＋ 段落」で段落を足す、「全文を編集」で文書全体をMarkdownのまま編集(PCは左右に並べて表示)
- 段落を空にして確定すると、その段落は消えます
- `Tab` / `Shift` + `Tab` で字下げ

編集キットのボタン:見出し(押すたびに大→中→小→なし)、太字、リンク、箇条書き、番号付き、チェック(押すたびに ☐→☑)、字下げ、戻す。「その他」に表、引用、区切り線、取り消し線、マーカー、コード、画像。

「保存」(`Ctrl` + `S`)の行き先は、使っているブラウザによって変わります。

| 環境 | 保存のしかた |
|---|---|
| PC の Chrome / Edge | 開いたファイルにそのまま上書き。元のファイルが分からないときは保存先を選ぶ |
| iPhone / iPad | 共有メニューが開く。「"ファイル"に保存」で保存先を選ぶ |
| それ以外 | ダウンロード |

保存していない編集は、この端末のブラウザに下書きとして残り、次に開いたとき復元されます。

### URLで渡す(iPhoneのショートカットなど)

URLの `#` のあとに本文を付けて開くと、そのまま表示します。

```
index.html#name=メモ.md&md=<URLエンコードした本文>
```

- `md` は必須、`name` は省略できます(省略すると「共有.md」)
- `#` 以降はサーバーに送られません。読み込んだあとはURLから取り除きます

iPhoneでは、ショートカットAppで次のように組むと、ファイルAppの共有メニューから開けます。

1. ショートカットの詳細で「共有シートに表示」をオンにし、受け取る種類を「ファイル」にする
2. 「テキストを取得」で、ショートカットの入力から本文を取り出す
3. 「URLエンコード」で本文をエンコードする
4. 「テキスト」に `https://<公開先>/index.html#md=` と書き、後ろにエンコードした本文をつなげる
5. 「URLを開く」でSafariに渡す

## 試作：Notion のように書ける編集画面(beta.html)

`beta.html` は、Markdownの記号を見ずに書ける編集画面の試作です。ビューアの設定メニューからも開けます。

- 行のはじめで「/」を押すと、見出し・リスト・表などのメニューが出る
- 文字を選ぶと、太字やリンクのボタンが浮かぶ(スマホは上に書式のバーが常に出る)
- 行の左の ⋮⋮ で段落ごと並べ替え
- `- ` `## ` `- [ ] ` と打つと、その場で箇条書き・見出し・チェックに変わる
- 開く・保存・下書きの復元・URLの `#` での受け取りは、ビューアと同じ

保存するとき、Markdownの書き方が少し整えられます(表の列幅がそろう、など)。先頭の `---` の情報欄(フロントマター)と改行コードはそのまま残します。

右上の「表示のみ」で、編集せずに読むだけの表示に切り替えられます。

「開く」→「Googleドライブ」で、ドライブの原本を開いてそのまま上書き保存できます(iPhoneでもPCでも)。開いたあとにドライブ側で更新されていたら、上書きする前に確かめます。権限は「このページで選んだファイルだけ」(`drive.file`)です。使うには `beta/src/drive.js` の `GOOGLE` に、Google Cloud で作ったクライアントID・APIキー・プロジェクト番号を入れてビルドします。空のままならこのメニューは出ません。文字は Inter と Noto Sans JP(Google Fonts)を使います。

編集部品は [Milkdown](https://milkdown.dev/)(MIT)です。`beta/` で `npm install && npm run build` を実行すると、部品ごと `beta.html` 1つにまとめ直します。

## 表示

**インデント**

- 入れ子の階層に縦のガイド線が入り、深さが目で追えます
- 階層ごとにマーカーが変わります(・→ ○ → ■ / 1. → a. → i.)
- コードブロックは元の字下げをそのまま保ちます

**表**

- 見出し行は固定され、スクロールしても消えません
- `|:--|--:|:-:|` の寄せ指定に従います
- 指定がない列でも、数値だけの列は自動で右寄せになります
- 幅が足りないときは表の中だけが横スクロールします

## 機能

| できること | 説明 |
| --- | --- |
| 目次 | 見出しから自動生成。読んでいる位置が光ります |
| テーマ | ライト / ダーク / OS設定に追従 |
| 文字サイズ・本文の幅 | 4段階 / 3段階。設定は次回も残ります |
| 印刷・PDF保存 | `Ctrl` + `P`。画面まわりは省いて本文だけ出ます |
| コードのコピー | コードブロックの右上のボタン |
| 自動更新 | 設定でオンにすると、開いたファイルの保存を検知して読み直します(Chrome / Edge) |
| 編集・保存 | 段落をその場で編集。上の「編集と保存」を参照 |

## 対応している記法

見出し(`#` と `===` の両形式)、段落、箇条書き、番号付きリスト、タスクリスト、入れ子リスト、表、引用(入れ子可)、コードブロック(フェンス / 4スペース)、行内コード、リンク(インライン / 参照 / 自動)、画像、強調、取り消し線、ハイライト(`==`)、水平線、脚注、YAMLフロントマター。

Markdownパーサは外部ライブラリを使わず、このファイルの中に書いてあります。

## 安全性

読み込んだファイルはどこにも送信されません。すべてブラウザの中だけで処理します。

Markdown内の生HTMLは、`script` や `onclick` などを取り除いてから表示します。

## 動作環境

Chrome / Edge / Firefox / Safari の最近のバージョン。

対応する拡張子は `.md` `.markdown` `.mkd` `.mdown` `.mdx` `.txt` です。文字コードはUTF-8。
